## ⚙️ Setup & Usage Guide

To get the best performance and use all features, follow these steps:

### 1. Installing the App
Download the `app-debug.apk` from the Releases section and install it on your device.

### 2. Setting up Shizuku (For Non-Rooted Devices)
Since Android doesn't allow apps to kill other apps natively, this app uses **Shizuku** to get ADB (Android Debug Bridge) permissions.
1. Download and install [Shizuku from the Play Store](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api).
2. Open Shizuku and start the service using **Wireless Debugging** (found in Developer Options).
3. Open **Background Killer** and tap on the **"SHIZUKU"** button.
4. Allow the permission popup.

### 3. Setting up the Aim System (Crosshair)
1. In the app, tap on the orange **"AIM"** button.
2. **Step 1:** Tap **"1. GRANT USAGE ACCESS"** and allow the app to access usage data (required to detect when a game is open).
3. **Step 2:** Tap **"2. SELECT GAMES"** and choose PUBG, Free Fire, etc. (The aim will only show in these games).
4. Drag the crosshair on the screen preview to set your desired position.
5. Choose your preferred shape and color.
6. Tap **"SAVE & START AIM"**. You will need to grant **"Display over other apps"** permission once.

### 4. Boosting the Game
1. Go to the app's main screen.
2. Tap on **"START"**. A persistent notification will appear (this keeps the app alive).
3. Open your game and enjoy the lag-free experience!

## ⚠️ Important Information
- **Battery Optimization:** Make sure to set the app to **"No Restrictions"** or **"Unrestricted"** in your phone's battery settings, otherwise, Android might kill the service in the background.
- **Anti-Cheat Warning:** The Aim System is a simple screen overlay (Crosshair). It does not modify game memory. However, always use third-party tools at your own risk.
